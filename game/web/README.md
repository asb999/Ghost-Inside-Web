# Ghost Inside：心灵调理师 · 第一关《留一个位置》

5–7 分钟的 3D Greybox。只验证一个核心体验：林澈替家人拿起三件事，身体逐渐变重；第一次无法跨过断层；在三段记忆里把责任还到合适的位置；发现被压住的异地调动通知；把自己的选择留下后，再次越过同一处断层。

进入游戏后先看到整体主视觉，再进入第一关介绍。完成页的“重新开始”会完整清空进度并回到整体开始页。

## 启动

```bash
cd game/web
npm install
npm start
```

默认地址：`http://127.0.0.1:4173/`。

开发与构建：

```bash
npm run dev
npm run build
```

## 操作

- WASD / 方向键：移动
- Space：跳跃
- E / Enter：拿起、放下、互动

没有答题、证据面板、心理评分或外部 AI 服务。失败不会死亡，物品不会丢失。

## 验收

在仓库根目录执行：

```bash
node .astra/harness/check.mjs
```

验收只通过正式移动、跳跃和互动完成整关，并检查负重曲线、四件物品状态、同一断层三次结果、零输入不推进、浏览器报错和六张关键截图。

截图保存在 `.astra/artifacts/leave-a-place/`。

## 当前范围

本轮是玩法验证版。场景使用简单几何体和已有家庭背景，不包含正式角色、美术、动画、配音、战斗、Boss、多结局或大地图。试玩确认核心闭环后，再进入正式视觉制作。

Ghost 已使用 Tripo 生成的轻量 GLB；加载失败时自动保留几何占位，不会阻断游戏。
