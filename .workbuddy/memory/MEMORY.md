# EvoMap_Game / Ghost Inside 项目长期笔记

## 项目定位
《Ghost Inside：心灵调理师》—— 玩家扮演「情绪调试师（Emotion Debugger）」进入他人内心，
把心理压力具象化为怪物，通过战斗+跑酷+记忆探索，帮当事人重新拿回解释自己的权利。
核心命题：未来的人如何在高度数字化的世界里保持自己还是一个人。

## 已锁定的设计决策
- **核心乐趣**：通过战斗和探索逐渐看懂这个人经历过什么（不是打怪爽感）
- **唯一值得投入的 AI 原生机制**：玩家每关说出一句判断，当场被对方检验
  （四档 `accept` / `revise` / `reject` / `hold`；拔掉 LLM 就退回选项树）
  `revise`/`reject` 必须给出下一步方向——拒绝是导航，不是惩罚
- **战斗以「转化」为胜利**：防御值降低 → 暴露记忆 → 找到保护意图 → 怪物转为可用能力（保留代价）
- **怪物三层结构**：外在行为 / 形成回忆 / 保护意图
- **三条红线**：不宣称疗效 · 不替当事人做人生决定 · AI 只读证据写反馈（绝不改事实）
- **AI 可控性**：固定事实图谱 + 证据白名单 + 一次重试 + 固定回退（断网也不能断流程）
- **人格三项指标**：自主性 / 一致性 / 稳定性，不能同时最大化
- **主反转**（v1.1 更新）：林澈不是讨厌医学，而是**从未真正拥有过选择的机会**——不知道哪些愿望属于自己，甚至没有明确的梦想；结局是「我不知道」（父亲非反派：父母说的是爱，孩子接收到的是责任）
- **第一关「最优人生」**（10-01 定稿）：痛点 A 乖孩子困境（内核）+ B 亏欠感（情感压力）+ D 稳定人生困境（现实）；核心交互「正确答案污染」（选项被系统逐个锁死，固定脚本即可）；BOSS「最优解 / Optimal Self」＝家庭期待 / 社会比较 / 算法推荐三重压力源
- **主角名一律用「林澈」**（ChatGPT 讨论里的「林默」是它临时起的名，视为同一人）
- **关系架构**（10-01 v1.2 定稿）：现实层（你＝心灵调理师 + Ghost ／ 林澈 + 情绪芯片与最优人生系统，三者同源——Ghost 出厂是芯片整理模块，执行过 47 次删除，后调岗）；意识空间三类存在：活的（你 / Ghost / 林澈心象，可对话）、系统具象（赞许收集者 / 最优解）、记忆回放（父母林远林宇陈默沈舟顾教授，**不可对话**——过去无法被说服）
- **Ghost 定稿**（教练式对话确认）：工具渐暖（系统手册腔→无证据句→共犯自白→四幕被格式化→缓存「可以慢慢想」）；共犯+牺牲都保留；少量冷面幽默（过度精准式，不毒舌）
- **称谓双名分工**：心灵调理师＝对外职业名（副标题/海报/结案文书）；情绪调试师＝系统内部称呼（工牌/Ghost 日常叫法）；文档不用单独「主角」二字，用「你（调理师）」「林澈（来访者）」
- **叙事结构 v1.2**：四条张力线（谁删了出口／五个活法／共犯 Ghost／真话算错——最优解只用真证据重排成错误结论，是三条红线的暗面镜像）× 五幕节拍（暖起→怯→冷谷→回暖→坠谷→燃→假平→再升→柔收）；反转错峰：中点揭示 47 次修改是他自己删的
- **人物数值以人物小传 docx 为准**：父林建国 52 / 母周敏 50 / 林宇 30 / 陈默 22 / 沈舟 38（叔叔，独立摄影师，非同龄人）/ 顾教授 60 / 林远 14

## 技术路线（2026-09-30 更新）
- **2D 像素 → 3D 动漫风 + 赛博朋克**（表现层升级，内核保留）
- **Phase 1**：网页 Three.js / WebGL 验证 → 10/5 晚 8 点线上提交
- **Phase 2**：转 Godot 4.7.2（Compatibility 渲染）→ 10/17 上海 Demo Day
- **AI 资产**：**Tripo AI** 积分模式（非 API；API 像抽盲盒）+ 2D 图生 3D + 角色拆件生成
- **美术**：动漫风+赛博朋克（深黑/低饱和蓝/故障红；真实记忆用暖白·琥珀）
- **地图主题来源**：来访者记忆中朋友/亲人「最戳他的一句话」
