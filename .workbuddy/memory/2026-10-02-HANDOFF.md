## 五、技术坑备忘（已修，防回归）

- 飞书表格行内 ≥2 处加粗会错位 → 每行只留一处加粗。
- `unlock()` → `_emit` → onBeatChange 重建当前节拍 UI 是最大 bug → main.js 用 lastBeat 守卫。
- garden interact 分支需 `stepSimulation(200)` 推进模拟；H03 断言 expected 七节拍（closed 不推 beat_enter，单独断言 case_closed 事件）；pollution 事件 id 从案例 JSON 动态读（PE1-PE5）。
- H06：fullFlow 必须带 `?provider=` query；mock provider 必须 CORS（`access-control-allow-origin: *` + OPTIONS 预检）。
- Chromium/网络需 `HTTPS_PROXY=http://127.0.0.1:6864`。
- 四条红线：不宣称疗效/不替当事人做人生决定/AI 只读证据写反馈/禁词表（治疗/治愈/疗效/诊断/抑郁/焦虑症+繁体），H07 扫描唯一豁免 `/agent_contract/forbidden_actions`。
