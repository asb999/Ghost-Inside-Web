## 重开与异常

| 检查项 | 通过标准 | 结果／备注 |
|---|---|---|
| 取消重开 | 点击“从头开始”后取消，当前证据、解释和结果不变 | |
| 确认重开 | 确认后证据、草稿、选择、效果、位置和结果全部清空 | |
| 空输入 | 给出清楚提示，不丢已选证据，不进入预览 | |
| 超长输入 | 200 字边界有明确限制，不造成界面破坏或请求重复 | |
| 请求中状态 | 显示等待文字；按钮防重复；可以取消或查看证据 | |
| 取消请求 | 取消后迟到响应不能改变证据、预览或结果 | |
| 超时 | 约 8 秒后可重试或进入备用互动，状态不丢失 | |
| 非法引用 | 服务返回未解锁证据时被拒绝，不写入当前选择 | |
| 越界动作 | 服务试图改写事实、同时开启两个效果或新增行动时被拒绝 | |
| 备用标识 | 使用备用互动后，全程持续显示“备用互动” | |
